The agentic coding template turns your AI coding assistant into a reliable member of the team, in a new
project or one that already exists. You set the goals and decide; the assistant plans, hands the work to
specialized sub-agents, proves its results, and keeps the project's state in the repository, so every
session picks up where the last one stopped. Setting it up takes one sentence in the chat.
